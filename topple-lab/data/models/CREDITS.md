# The Topple Lab's photographed models: sources and licence

Every model here is a [Poly Haven](https://polyhaven.com) model (1K glTF),
**CC0** (public domain: free to use, change and share, no credit required;
credited here anyway). Downloaded 2026-11-22 (developer: "Yes to both"),
each file checked against the MD5 Poly Haven's API gives (all matched). Cut
down by Claude's helper script (quadric edge collapse onto the model's own
corners) to the triangles below, kept as a small JSON
(`src/core/model-data.js` reads it); its pictures 512 or 256 px from the 1K
JPGs: `_col` (colour), `_nor` (normal, OpenGL), `_arm` (ambient occlusion,
roughness, metalness).
