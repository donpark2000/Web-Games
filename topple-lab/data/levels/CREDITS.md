# The Topple Lab's photographs for levels 2-5: sources and licence

Every file in this folder is a smaller copy of a file from
[Poly Haven](https://polyhaven.com) or [ambientCG](https://ambientcg.com),
all **CC0** (public domain: free to use, change and share, no credit
required; credited here anyway), but for NASA's moon (below). Downloaded 2026-11-22 (developer: "Yes to
both"); the Poly Haven files checked against the MD5 its API gives (all
matched; ambientCG gives none). Made smaller by Claude's helper script
(headless Edge's canvas): surfaces 512 or 256 px from the 1K JPGs; the sky
4096 x 2048 from the 8192 x 4096 tonemapped JPG, 1.16 times as bright.

Files: `_col` (colour), `_nor` (normal map, OpenGL), `_arm` (ambient
occlusion, roughness, metalness).
