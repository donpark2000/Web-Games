# The Topple Lab park's photographs: sources and licence

Every file in this folder is a smaller copy, or a cut-out, of a file from
[Poly Haven](https://polyhaven.com) or [ambientCG](https://ambientcg.com),
all **CC0** (public domain: free to use, change and share, no credit
required; credited here anyway). Downloaded 2026-11-20 (developer: "Yes,
download them"); the Poly Haven files checked against the MD5 its API gives
(all matched; ambientCG gives none). The lab's copies made by Claude's
helper scripts (Windows' own imaging, high-quality bicubic): the sky 4096 x
2048 from the 8192 x 4096 tonemapped JPG; the lawn 512 x 512 from the 1K
JPGs; the leaf 96 x 192 PNG cut from the model's leaf sheet, its black
background made see-through.

The bark on the park's tree and slingshot is the main site's
(`data/topple/knotted_pine_bark_*`, see `data/topple/CREDITS.md`).
