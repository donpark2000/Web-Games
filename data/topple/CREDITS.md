# Topple!'s photographs: sources and licence

Every file in this folder is a smaller copy of a file from
[Poly Haven](https://polyhaven.com), all **CC0** (public domain: free to use,
change and share, no credit required; credited here anyway). Downloaded
2026-11-11 through Poly Haven's API, each checked against the MD5 the API
gives (all matched); the game's copies made by Claude's helper scripts
(Windows' own imaging, high-quality bicubic): textures 512 x 512 from the
1K JPGs, skies 4096 x 2048 from the tonemapped JPGs, as JPEG.

Files: `<asset>_col.jpg` (colour), `_nor.jpg` (normal map, OpenGL),
`_arm.jpg` (ambient occlusion, roughness, metalness) or `_rough.jpg`
(roughness); `sky_<asset>.jpg` (a 360° photo).
